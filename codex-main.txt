Runtime / Connection Status (ArduPilot via apm.launch.py)
- State topic: /mavros_node/state  
  ros2 topic echo /mavros_node/state mavros_msgs/msg/State --qos-reliability reliable --qos-durability transient_local 
  → menampilkan connected, armed, mode, system_status
- Extended state: /mavros_node/extended_state  
  ros2 topic echo /mavros_node/extended_state  
  → menampilkan status landed / in-air
- Arming:  
  ros2 service call /mavros_node/mavros_node/arming mavros_msgs/srv/CommandBool "{value: true}"  
  ros2 service call /mavros_node/mavros_node/arming mavros_msgs/srv/CommandBool "{value: false}"  # disarm
- Set mode:  
  ros2 service call /mavros_node/set_mode mavros_msgs/srv/SetMode "{custom_mode: 'GUIDED'}"
- Takeoff (auto 2 m):  
  ros2 service call /mavros_node/mavros_node/takeoff mavros_msgs/srv/CommandTOL "{altitude: 2.0, latitude: 0.0, longitude: 0.0, min_pitch: 0.0, yaw: 0.0}"
- Manual thrust (uji static spin motor di tanah):  
  ros2 topic pub /mavros_node/setpoint_attitude/thrust std_msgs/msg/Float32 "{data: 0.1}" -r 20  
  (0.1 = 10% throttle; harus diulang >2 Hz, jika tidak autopilot failsafe)  
  Cek PWM via: ros2 topic echo /mavros_node/rc/out

Build Error — Root Cause & Fix
- Symptom: colcon fails with AttributeError: module importlib_metadata has no attribute EntryPoints when importing setuptools
- Root cause: On Ubuntu 20.04/Python 3.8, user-installed setuptools (new) expects EntryPoints API present only in newer importlib_metadata, but system importlib_metadata (apt) is old (1.x). This version skew breaks setup.py discovery
- Fix (one-time): python3 -m pip install --user --upgrade importlib_metadata setuptools wheel
- Preventive: install_foxy.sh now upgrades importlib_metadata>=4.6. build_kaertei.sh checks compatibility and auto-upgrades if missing

Additional Build Error — packaging mismatch
- Symptom: TypeError: canonicalize_version() got an unexpected keyword argument 'strip_trailing_zero' during setup/egg_info
- Root cause: New setuptools expects newer packaging API; older packaging lacked this kw arg
- Fix (one-time): python3 -m pip install --user --upgrade packaging setuptools wheel (we now use packaging 24.2+)
- Preventive: install_foxy.sh upgrades packaging; build_kaertei.sh validates via from packaging.utils import canonicalize_version and auto-upgrades if needed

=== KAERTEI Drone — MAVROS Interface Map (ArduCopter v4.6.2, ROS 2 Foxy) ===

1. State & Status
- /mavros_node/state                → FCU state (connected, armed, mode)
- /mavros_node/extended_state       → Extended state (landing, VTOL, etc.)
- /mavros_node/statustext/recv      → Text warnings/errors from FCU

2. Arming & Mode (services)
- /mavros_node/mavros_node/arming   → mavros_msgs/srv/CommandBool {value: true|false}
- /mavros_node/set_mode             → mavros_msgs/srv/SetMode {custom_mode: 'GUIDED'}
- /mavros_node/mavros_node/takeoff  → mavros_msgs/srv/CommandTOL
- /mavros_node/mavros_node/land     → mavros_msgs/srv/CommandTOL

3. RC & PWM
- /mavros_node/rc/in                → RC input channels
- /mavros_node/rc/out               → PWM outputs to ESC (show when armed)
- /mavros_node/rc/override          → RC override (manual control)

4. Setpoints
- /mavros_node/setpoint_attitude/thrust  → std_msgs/Float32 (0.0–1.0 thrust)
- /mavros_node/setpoint_attitude/cmd_vel → geometry_msgs/Twist
- /mavros_node/setpoint_velocity/cmd_vel → geometry_msgs/TwistStamped
- /mavros_node/setpoint_raw/local        → Position/velocity setpoint

5. Sensors / Position
- /mavros_node/local_position/pose       → Local ENU pose
- /mavros_node/global_position/global    → Global GPS position
- /mavros_node/global_position/raw/fix   → GPS fix raw
- /mavros_node/imu/data                  → IMU orientation
- /mavros_node/imu/mag                   → Magnetometer
- /mavros_node/imu/temperature           → IMU temp

6. Parameters (services)
- /mavros_node/param/get            → mavros_msgs/srv/ParamGet {param_id: '...'}
- /mavros_node/param/set            → mavros_msgs/srv/ParamSet {param_id: '...', value: {...}}
- /mavros_node/mavros_node/list_parameters
- /mavros_node/mavros_node/get_parameters

7. Miscellaneous
- /mavros_node/sys_status           → Battery, load, drop rate
- /mavros_node/vfr_hud              → Airspeed, throttle %, climb
- /mavros_node/esc_status           → ESC telemetry
- /mavros_node/actuator_control     → Raw actuator command

=== Notes ===
- ArduCopter modes: STABILIZE (default), GUIDED, GUIDED_NOGPS, LOITER, AUTO, RTL, etc.
- OFFBOARD mode is PX4-only → not available in ArduPilot.
- Parameters like MOT_SPIN_ARMED must be changed via MAVLink param (MAVProxy / QGroundControl).
- ros2 param set only works for ROS node params, not FCU params.
