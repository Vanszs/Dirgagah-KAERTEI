Build Error — Root Cause & Fix
- Symptom: colcon fails with AttributeError: module `importlib_metadata` has no attribute `EntryPoints` when importing setuptools.
- Root cause: On Ubuntu 20.04/Python 3.8, user-installed `setuptools` (new) expects `EntryPoints` API present only in newer `importlib_metadata`, but system `importlib_metadata` (apt) is old (1.x). This version skew breaks `setup.py` discovery.
- Fix (one-time): `python3 -m pip install --user --upgrade importlib_metadata setuptools wheel`
- Preventive: `install_foxy.sh` now upgrades `importlib_metadata>=4.6`. `build_kaertei.sh` checks compatibility and auto-upgrades `importlib_metadata` if missing.

Additional Build Error — packaging mismatch
- Symptom: TypeError: `canonicalize_version() got an unexpected keyword argument 'strip_trailing_zero'` during setup/egg_info.
- Root cause: New `setuptools` expects newer `packaging` API; older `packaging` lacked this kw arg.
- Fix (one-time): `python3 -m pip install --user --upgrade packaging setuptools wheel` (we now use packaging 24.2+).
- Preventive: `install_foxy.sh` upgrades `packaging`; `build_kaertei.sh` validates via `from packaging.utils import canonicalize_version` and auto-upgrades if needed.
